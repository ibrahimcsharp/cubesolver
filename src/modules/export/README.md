# Export

PDF booklet (jsPDF) and MP4 video (MediaRecorder + ffmpeg.wasm).

`cubeRenderer.ts` (off-screen 3D cube for any step and turn), `timeline.ts` (steps with before/after pictures), `pdf.ts` (booklet), `video.ts` (MP4 via WebCodecs + mediabunny, WebM fallback). See docs/decisions/0002-export-libraries.md.
