# Camera

`useCamera.ts`: webcam access (start/stop, camera choice, plain-English errors) and `grabFrame` to copy a video frame into pixels. The camera is always released when leaving the page.

`videoFrames.ts`: steps through an uploaded video a few frames per second (handles recordings that don't store their length). `thumbnail.ts`: small picture of a captured side.

**Built in:** Phase 3 (done), Phase 5 (video upload, done)
