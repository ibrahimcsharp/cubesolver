# Cube model

Stores the 54 stickers as a facelet string (order U, R, F, D, L, B), applies moves, and checks that a cube is valid and solvable.

**Built in:** Phase 1 (done). Files: `cubie.ts` (piece model and moves), `facelets.ts` (sticker view), `orientation.ts` (how the cube is held), `validate.ts` (plain-English checks), `random.ts` (test scrambles).
